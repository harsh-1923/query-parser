Use It in Your Code

Pass the time phrase, your reference instant and your time zone. You get back a half-open range, or unsupported, never a guess 

import { normalizeTime } from "@qp/time"

const r = normalizeTime("last week", {
  reference: "2026-10-12T10:00:00Z", // your "now"
  timeZone: "Asia/Kolkata",        // your zone
})

// r → { ok: true, granularity: "week",
//       from: "2026-10-04T18:30:00.000Z",   // Mon 5 Oct, 00:00 IST
//       to:   "2026-10-11T18:30:00.000Z" }  // Mon 12 Oct, exclusive

A Small Experiment. Still Growing

The SDK will tag every part of a query (who, where, what kind, when) with a tiny model and map it to your product's filters. Today only the time normalizer exists. The highlighting above is a demo stand-in for the tagger.

In spike S4 it covered every time phrase in our test queries and 84.9% of a held-out set, with zero wrong answers. Unfamiliar wording comes back as unsupported. Read the results ↗
