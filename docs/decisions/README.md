# Decision records

One file per significant decision, numbered in order: `NNNN-short-title.md`.

Each record has: **Status** (proposed / accepted / superseded by NNNN), **Context**, **Options**,
**Decision**, **Consequences**. Keep them short. Don't edit an accepted record to change the
decision; write a new one that supersedes it.
